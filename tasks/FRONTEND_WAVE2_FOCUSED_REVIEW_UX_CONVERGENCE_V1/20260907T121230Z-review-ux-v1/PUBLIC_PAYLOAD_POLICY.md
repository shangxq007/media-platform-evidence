# Public payload classification and reproduction boundaries

This is an evidence delivery, not a product candidate/commit or independent acceptance. BYTE_EXACT artifacts are copies from this external task package, including failed attempts. Derived index/provenance/report metadata is identified separately. Source before/after, exact task patch, complete inherited dirty-implementation patch, build assets/manifest and raw gate outputs bind to the reported implementation tree.

The baseline is the Owner-accepted dirty implementation tree, not the public backend branch. To reconstruct outside any registered worktree: obtain product base commit f5e19cf53fd010eea2935dd29557e82a879e042c, materialize its files in a disposable location, then apply COMPLETE_IMPLEMENTATION.patch there. Its expected complete tree is FINAL_TREE.txt. TASK_DELTA.patch instead applies only to the accepted implementation tree. Do not stage or alter the live product worktree. The original external materialize.py and gate.py show the identity/build method and retained local paths; they are audit records, not a portable installer. Dependencies/Chromium/venv must match the recorded environment; no dependency installation or backend runtime is included. Supporting source is a bounded set, not a full dependency distribution.

The inventory source copies are tied to two explicitly different immutable identities; they must not be overlaid wholesale onto the frontend source. The backend reference is an observed local origin/main commit, not evidence about concurrent backend work or actual delivery.

Omitted: private configuration, vault contents, authentication values, account homes, full personal context/Memory, raw agent session transcripts, browser profiles, node_modules, external Git object stores/index binaries, full repository snapshot, unrelated historical task directories and backend runtime data. Auth output contains no credential values. Smoke's exact local denied auth bootstrap attempts remain visible, not reported as zero POSTs. Supplemental app-unused failure and stopped Node snapshot-cache denial remain visible. No historical failure report is rewritten to PASS.

All payload files except MANIFEST.sha256 are hashed. Remote readback is recorded in a detached receipt after publication so the payload has no self-hash cycle. Public source/fixture comments mentioning credentials or identifiers are not real credential values; publication additionally checks actual transient credential absence and excludes configuration/profile paths.
