# Pre-freeze closure design

This bounded closure extends the accepted A-only shell through the existing `SelectionContext` and `InteractionIntent` dispatcher. It adds exactly two explicitly synthetic NLE clip fixtures. Modifier selection (Ctrl/Meta), an explicit primary, contraction, scope invalidation, and proposal invalidation are all represented by the existing `selectedObjects`, primary and context revision fields.

The presentation remains deliberately non-canonical: frozen V1/A1 lanes, a 0–20 simulated-step scrubber, no decoded media, no authoritative geometry, and no audio-gain operation. The Chinese two-clip volume request is a synthetic proposal targeting both fixtures; Modify remains available and canonical Apply is unavailable. `SYNTHETIC_EFFECTIVE_ACTION_PROJECTION` is explanatory only, never an execution credential.

The creator hierarchy is intent → selected targets → proposal → warnings → actions. Synthetic and authorization evidence lives in Details and diagnostics; it remains accessible but is not the primary reading order. Mobile Agent starts as an internally scrolling 62dvh sheet and can be intentionally expanded to 90dvh. The existing dialog retains backdrop, Escape, focus trap/restoration and scroll containment behavior.

Safety limits: no B runtime surface, backend source, API redesign, fake server planning, role/plan checks, canonical mutation execution, browser run, server run, Git write, or external ledger write. Existing typed timeline gateways were audited read-only and retained because they already provide the established Add Media Clip boundary; this closure does not manufacture parallel gateways.
